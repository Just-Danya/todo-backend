# Todo
Задачник, для управления задачами (todo) с использованием REST API.


## Технологии
- Java 25
- Spring Boot
- PostgreSQL
- Maven
- Docker
- Spring Data JPA
- Spring Validation
- PostgreSQL JDBC Driver

Основные используемые технологии, здесь записаны которые уже добавлены в проекте, также их можно найти в файле `pom.xml`.

## Запуск проекта
Для запуска проекта нужно добавить application.properties файл в папку `src/main/resources` и добавить всё необходимое туда


Таски будут в чате!
